BOKU BIRTHDAY WEBSITE

The public website is built automatically from the dist folder using GitHub Pages.

TO ADD THE FIVE PHOTOS IN VS CODE

1. Open dist/images.
2. Add five JPG files named exactly:
   photo-1.jpg
   photo-2.jpg
   photo-3.jpg
   photo-4.jpg
   photo-5.jpg
3. Save, commit, and push the changes.

GitHub will rebuild the public website automatically after every push.
